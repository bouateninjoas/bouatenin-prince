ENSEMBLES & TABLEAUX

Somme des éléments distincts

Additionner les valeurs présentes dans un seul des deux ensembles (différence symétrique). Les tableaux représentent des ensembles, donc ne contiennent pas de doublons. 

Algorithme SommeDistincts
Variables
  A, B : tableaux d'entiers
  nA, nB, i, j, somme : entier
  present : booléen
Début
  Lire nA, nB
  Lire A[1..nA], B[1..nB]
  somme ← 0

  Pour i de 1 à nA faire
    present ← Faux
    Pour j de 1 à nB faire
      Si A[i] = B[j] alors
        present ← Vrai
      FinSi
    FinPour
    Si NON present alors
      somme ← somme + A[i]
    FinSi
  FinPour

  Pour i de 1 à nB faire
    present ← Faux
    Pour j de 1 à nA faire
      Si B[i] = A[j] alors
        present ← Vrai
      FinSi
    FinPour
    Si NON present alors
      somme ← somme + B[i]
    FinSi
  FinPour

  Afficher somme
Fin
Exemple

A = [3, 1, 7, 9]  ·  B = [2, 4, 1, 9, 3]

Somme : 7 + 2 + 4 = 13
02
VECTEURS DE ℝ

Produit scalaire

Les vecteurs sont représentés par des tableaux de même dimension m. Le produit scalaire est la somme des produits de leurs composantes.

A. Avec une procédure

Passage des paramètres : v1, v2 et m en entrée ; ps en sortie (modifié par la procédure).

Procédure dot_product(v1, v2 : tableaux de réel ;
                      m : entier ; Sortie ps : réel)
Variables
  k : entier
Début
  ps ← 0
  Pour k de 1 à m faire
    ps ← ps + v1[k] × v2[k]
  FinPour
FinProcédure

Algorithme Orthogonalite
Variables
  v1, v2 : tableaux de réel
  n, m, i : entier
  ps : réel
Début
  Lire n, m
  Pour i de 1 à n faire
    Lire v1[1..m], v2[1..m]
    dot_product(v1, v2, m, ps)
    Si ps = 0 alors
      Afficher "Les vecteurs sont orthogonaux"
    Sinon
      Afficher "Les vecteurs ne sont pas orthogonaux"
    FinSi
  FinPour
Fin

B. Avec une fonction

Valeur retournée : la fonction renvoie directement le produit scalaire ; aucun paramètre de sortie n'est nécessaire.

Fonction dot_product(v1, v2 : tableaux de réel ; m : entier) : réel
Variables
  k : entier
  ps : réel
Début
  ps ← 0
  Pour k de 1 à m faire
    ps ← ps + v1[k] × v2[k]
  FinPour
  Retourner ps
FinFonction

Algorithme OrthogonaliteAvecFonction
Variables
  v1, v2 : tableaux de réel
  n, m, i : entier
Début
  Lire n, m
  Pour i de 1 à n faire
    Lire v1[1..m], v2[1..m]
    Si dot_product(v1, v2, m) = 0 alors
      Afficher "Les vecteurs sont orthogonaux"
    Sinon
      Afficher "Les vecteurs ne sont pas orthogonaux"
    FinSi
  FinPour
Fin

En calcul numérique sur des réels, on remplace généralement le test exact ps = 0 par |ps| ≤ ε, où ε est une petite tolérance.

✳ Les deux versions du produit scalaire calculent le même résultat.
