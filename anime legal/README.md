# Yume — guide anime officiel

Site statique pour trouver des services d'animation qui diffusent leur catalogue via leurs plateformes officielles. Aucun épisode ni film n'est hébergé ou intégré sur ce site.

## Lancer

Ouvre `index.html` dans un navigateur. Les filtres s'exécutent localement, sans compte, dépendance JavaScript ou collecte de données.

Les liens conduisent aux sites officiels des services. Les droits, tarifs, offres et catalogues varient selon les régions : vérifie les informations directement auprès du fournisseur.
